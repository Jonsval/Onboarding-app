Módulo 1: Ecosistema y Flujo de Trabajo

Instructor: Sofía Valenzuela · Actualizado Agosto 2026

Puntos Clave del Video:

  • Canales de Slack: #general para anuncios, #dev-team para consultas técnicas, #incidentes-criticos-alerta para bloqueos de producción.
  • Convención de Commits: Usamos Conventional Commits (feat:, fix:, docs:, refactor:).
  • Ramas en Git: main siempre está protegida. Cada funcionalidad nace de main con el formato feature/TICKET-descripcion.
  • Revisiones de Código: Todo Pull Request debe tener al menos una aprobación y pasar el pipeline de CI/CD antes de fusionarse.
